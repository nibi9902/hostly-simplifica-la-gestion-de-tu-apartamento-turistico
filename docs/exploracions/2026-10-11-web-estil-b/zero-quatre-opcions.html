El 0 €, de quatre maneres

És la franja que tancava l'entrada d'abans: «Otras apps te lo cobran cada mes. 0 € en Hostly. Para siempre.», amb les tres xifres, els botons i les insígnies de Booking, Airbnb i Google. Els textos són els d'ara. Les tres primeres anirien just després de l'entrada. La quarta no té franja pròpia: es fica dins de «Gratis para siempre» i així el 0 € només surt una vegada.
